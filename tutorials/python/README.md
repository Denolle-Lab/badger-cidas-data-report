# Python Tutorials

This directory contains Python scripts for the BADGER-CIDAS project.

## Planned Tutorials

1. **Loading and plotting broadband seismometer data**
   - Read seismic data formats (MiniSEED, SAC)
   - Basic time series visualization
   - Spectral analysis

2. **DAS fiber optic data processing**
   - Loading DAS HDF5 files
   - Waterfall plots
   - Channel selection and filtering

3. **Joint broadband-DAS analysis**
   - Co-located comparison
   - Cross-correlation techniques
   - Event detection

## Getting Started

Activate the conda or pixi environment before running scripts:

```bash
conda activate seismic-tutorials
# or
pixi shell
```

## Adding New Tutorials

Place new tutorial scripts in this directory with descriptive names.
Include docstrings and comments for clarity.
