# MATLAB Tutorials

This directory contains MATLAB scripts for the BADGER-CIDAS project.

## Planned Tutorials

1. **Broadband seismometer analysis**
   - Loading seismic data
   - Time-frequency analysis
   - Filter design and application

2. **DAS array visualization**
   - Matrix-based DAS data handling
   - Waterfall displays
   - Channel trace plotting

3. **Signal processing workflows**
   - Denoising techniques
   - Phase picking
   - Amplitude measurements

## Requirements

MATLAB R2020a or newer recommended.

Required toolboxes:
- Signal Processing Toolbox
- (Optional) Seismic Analysis Code (SAC) for MATLAB

## Usage

Run scripts directly in MATLAB or from command line:

```matlab
run('script_name.m')
```

## Adding New Tutorials

Place new MATLAB scripts in this directory with `.m` extension.
Use clear variable names and include comments.
