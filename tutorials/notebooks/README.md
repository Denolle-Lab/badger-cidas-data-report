# Jupyter Notebooks

This directory contains interactive Jupyter notebooks for the BADGER-CIDAS project.

## Planned Notebooks

1. **Introduction to ObsPy for seismic data**
   - Interactive tutorial on ObsPy basics
   - Reading and writing seismic formats
   - Stream manipulation

2. **DAS data exploration**
   - Interactive visualization of DAS arrays
   - Parameter exploration
   - Quality control

3. **Broadband and DAS comparison**
   - Side-by-side analysis
   - Interactive plotting
   - Case studies from BADGER-CIDAS deployment

## Starting Jupyter

From the repository root:

```bash
# With conda
conda activate seismic-tutorials
jupyter notebook

# With pixi
pixi run jupyter
```

The notebook interface will open in your browser.

## Creating New Notebooks

1. Click "New" → "Python 3" in the Jupyter interface
2. Save with a descriptive name
3. Add markdown cells for documentation
4. Include clear outputs and visualizations
